## 0. Executive summary

* **No power has dedicated VR code in DOTO today.** Powers go through the generic left-hand path: the power hand's
  trigger becomes the native LT hold (aim) / release (cast), and while that trigger is held the existing gameplay-aim
  producer writes the hand ray into the player camera's aim block (`cam+0x252ac` origin, `+0x252b8` axis).
* The D2 **hand-aimed Blink hook is OFF in DOTO**: its pin for D2 `0x6205e0` does not match DOTO `0x674200` (the
  function was recompiled: `48 8b c4 57 48 81 ec 90 00 00 00 80 b9 a4 ...` against the D2 pin
  `48 8b c4 55 57 48 8d 68 a1 ...`), so `install()` throws and the session logs "Hand-aimed Blink disabled". It would be
  useless anyway: `0x674200` is the Blink power, Billie aims Displace through a sensor.
* **Displace, Void Strike and the Voltaic Gun all read the same camera aim block.** The mod already writes it from the
  hand at stage 7, so hand-aimed Displace is *probably* already live while the trigger is held (INFERRED; UNVERIFIED in
  sim). A deterministic hook (`0x3e21b0`, a clone of `NativeBlinkAim`) is the fallback.
* **New finding: Void Strike is not a power component.** It is a variant of the Slash player state
  (`arkPlayerStateSlash`, vtable `0x1d0b978`): a **held attack** with the Void Strike attribute owned, committed when the
  hold time passes a decl threshold (`decl+0xa0`), costing mana (`decl+0xf0`), targeting through the VoidStrikeSnap
  sensor (`0x25`) which copies the **camera aim block**, and taking a direction (0..3) from the **movement stick**. So
  the mod's existing sword charge (which emits a 340 ms RT hold) may or may not produce a Void Strike depending on that
  one decl value. That is the highest-value single read.
* Foresight moves the **player entity itself** (the "spirit") under the normal player camera; head tracking should
  just work, but the mod's **full body, physical hand contact and grab follow the player entity** and must be gated off
  in spirit states 3/4, and the exit restores the body's origin and **yaw** (a heading jump in VR).
* Semblance has no ray: it is armed from inside the choke. The VR work is input routing (LT must reach the game during
  a choke) plus a gesture.

### 1.3 Hand-aimed Blink (D2) and why it is off in DOTO

* Class `NativeBlinkAim`, `src/native_blink_aim.hpp:93-267`: MinHook on D2 `0x6205e0` (pins `:44-56`), gate
  `power+0xa4!=0 && +0xa5==0` (`:143-145`), writes 36 direction bytes at `cam+0x25288` before the original (`:158-165`),
  status object `blink_aim` (`:257-266`; emitted `dxgi_probe.cpp:16163`).
* Session: installed when left aim is requested (`dxgi_probe.cpp:19174-19185`), knob `build/no-hand-blink` = observe only;
  hand published at `:10603`, cleared at `:10683, :10691, :10702`; disabled at `:19856`.
* DOTO: translate.py maps `0x6205e0 -> 0x674200` (aligned 4/8), thunk `0x954d00 -> 0x9cd420` (exact, offsets.json "bytes"
  rule accepts it), call `0x954d2e -> 0x9cd44e` (`e8 ad 6d ca ff` -> `0x674200`, PROVEN). **The 32-byte function pin fails**
  (bytes above, PROVEN), so `install()` throws "Native blink aim function differs" -> recoverable note, `blink_aim.installed`
  false (feature-parity row "hand-aimed Blink -> DOTO Displace: dead"). In DOTO `power+0xa4` and the camera is at
  `power+0xe8`, not `+0x160`, so even a re-pinned hook would read the wrong field.

### 3.1 Displace

* **Gesture**: hold the power-hand trigger = aim (game StartAim), release = place (Cast). **Swap** = a deliberate second
  action while a marker exists: default the power button tap (LT tap, which is the game's own swap), optional "pull the
  casting hand to the chest" gesture mapped to a 150 ms LT pulse (reuse `gesture_cast_until`, `dxgi_probe.cpp:17675-17684`).
  To stop an aimed place from swapping by accident, only treat a tap as swap when `has_target` is false at press and a
