# v678 test release: the counter-serum instruction, independent of the map tutorial

The v677 native script-message probe worked, but the Mission 3 cure instruction still did not
appear. The game data explains why:

- `models/campaign/institute/cure_hypatia.tutorial` is a **Kiscule HUD tutorial** whose title,
  description and content are `ui_sm_cure_hypatia` ("Press <BLOCK> to inject counter-serum").
- Its Kiscule graph shows/hides it from `arkKisculeNodeNPCInteractionNotification` (node 1567231016,
  bool test 1906045429). That notification is generated by the native NPC-interaction path, not by
  the HUD InteractionWindow. When the notification does not fire, there is no native art for the
  mod to capture, so v677 had nothing to place.
- A session check also showed **`Alexandria Hypatia (dead)` / Carry** on the body. With the NPC
  dead, the game cannot offer the cure at all.

## What v678 changes

- A fallback tutorial card is generated once with the same GDI card/font path as the controller
  glyphs and drawn on the existing head-locked tutorial slot. It is suppressed whenever a real
  native HUD script message is visible.
- When the target is the authored entity whose name contains `hypatia`, the card shows one of:
  - **Press grip to inject counter-serum** when the player's inventory contains the syringe;
  - **Craft the counter-serum in the lab first** when it does not;
  - **Hypatia is dead - load a save before the fight** when `+0xd1` has the dead/unconscious bits.
- The native Kiscule message remains the preferred source. The card covers the case where its
  notification does not fire in VR.
- Diagnostics: `cure_prompt_frames`, `cure_prompt_state` (1 dead, 2 serum, 3 no serum).

## Test

1. Load a save **before** Hypatia dies, with the counter-serum crafted.
2. Look or point at her. The card should appear on the panel ahead of you.
3. If it says "Hypatia is dead", that save is after the fight; load an earlier one.
4. If it says "Craft the counter-serum in the lab first", finish the lab crafting and return.

## Limits

- Not headset-tested. The checkout has no pre-kill Mission 3 save, and the last session's body
  was already dead.
- The card is English; the game's own localized tutorial remains preferred when it appears.
- The fallback is only a readable instruction. It does not change the game's cure eligibility.
