Notes:
- The research note (section 8C) proposed keyframed hknp hand bodies. The build does not do that. `hand_contact.hpp` says it is a software contact model, "not a hknp body", because creating a keyframed body is untested.
- The research note's starting numbers were 10 kg and 4 m/s. Code uses 12 kg for "heavy" and 4 m/s for ordinary push. Both are marked as guesses to tune in the note.
- The 0.4 s figure from the requester is the `late` default (400 ms), counted after the 100 ms window. A trigger can therefore join up to about 500 ms after the grip press. PLAYING.md says "within about half a second" to match the code. Confirm which number is wanted.

## 2. Tools (run from the repo root)

- `tools/hand_lab.sh [tag] [corvo|emily] [--snapshot FILE[:index]] [--refit] [--palette FILE[:index]] [--write-geometry FILE] [--lift-mm N]` writes `artifacts/hand-lab/<tag>/index.html`. It compiles whatever is in src/ right now. Needs `artifacts/fullbody-assets` (local, never committed). `--snapshot` replays one recorded solver input. `--palette` draws the hand the game submitted (`artifacts/arm-palettes.jsonl`).
- `tools/push_lab.sh [tag]` writes `artifacts/push-lab/<tag>/index.html`. Offline, no game, no asset pack. Its scenarios are synthetic, with timing copied from the sim script and a 7 cm offset said to reproduce the live v507 onset. It is not a replay of recorded input.
- `bash tools/sim_saves.sh in|reset|out`: `in` moves the user's saves to `artifacts/save-backups/current-user-saves` and installs the test save; `reset` puts the test save back between runs; `out` restores the user's saves. Game must be closed.
- `bash tools/simrun.sh <dll version> <name> <selftest args>`: closes the sim game (graceful, forced after 30 s), resets the save, runs `vr_selftest.py --dll d2vr_render_probe_arm_v<ver>.dll ... --launch` with a 900 s timeout, writes `artifacts/build-logs/v<ver>-<name>.log`, prints PASS/FAIL.
- `tools/vr_selftest.py` (1558 lines): `--scenario` takes names including hold, holdneck, orbit, orbitneck, orbitfist, carry, drag. `--near` takes bottle, corpse, npc and others. `--bottle-name` picks a bottle. `--script FILE` plays a recorded script, with `--script-shift`, `--script-head-pitch`, `--script-hand-pitch`. Orbit puts the head on a 0.40 m sphere around a held object (script v5, DLL v480 or later). "Showcase" is a carry sequence described in a comment near line 374; I did not confirm it as a named scenario.
- `tools/regress_report.py --version N` or `--logs GLOB`, add `--embed` for one HTML file with thumbnails inlined. Writes under `artifacts/reports/`.
- `tools/request_vr_capture.py --request LABEL --wait SECONDS`: asks a running game for native projection snapshots and waits for four images (max 60 s). Sends no game input.
- `tools/hand_pose_lab.cmd`: compiles the hand lab harness (called by `hand_lab.sh`).
